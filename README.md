Hospital Management System — OS Simulation
📌 Overview

This project is a Hospital Management System Simulator designed to demonstrate core concepts of Operating Systems using a real-world analogy.

It simulates how patients are processed in a hospital using:

CPU Scheduling Algorithms
Memory Management Techniques
Multiprogramming Concepts
🎯 Objective

To visualize and understand how operating system concepts work in real-life scenarios by mapping:

Patient → Process
Doctor → CPU
Ward → Memory Block
Treatment → Execution
