# 🏥 Hospital Management System — OS Simulator

A desktop application built with **Python** and **Tkinter** that simulates important **Operating System concepts** using a hospital environment as a real-world example.

The project demonstrates:

* CPU Scheduling Algorithms

  * FCFS
  * SJF
  * Priority Scheduling
  * Round Robin

* Memory Management Algorithms

  * First Fit
  * Best Fit
  * Worst Fit

The simulator includes a live patient queue, memory visualization, Gantt chart, and performance statistics such as waiting time, turnaround time, CPU utilization, and memory utilization.

This project was developed for academic purposes as part of the Operating Systems course.
